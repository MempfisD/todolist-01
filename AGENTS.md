# AGENTS.md

Инструкции для ИИ-агентов, работающих с этим репозиторием.

## Обзор проекта

Учебный проект TODO-приложения (IT-INCUBATOR Todolist). Сейчас это только вёрстка: данные захардкожены, состояния и обработчиков событий нет.

## Стек

- React 19.0.0 и React DOM 19.0.0
- TypeScript 5.7.2
- Vite 6.0.6 с плагином `@vitejs/plugin-react-swc` 3.7.2
- Vitest 2.1.8 (подключён, но тестов пока нет)
- Пакетный менеджер: pnpm (есть `pnpm-lock.yaml`)

## Команды

- `pnpm i` — установка зависимостей
- `pnpm dev` — dev-сервер на порту 3000 (`http://localhost:3000`)
- `pnpm build` — `tsc -b && vite build`
- `pnpm test` — запуск Vitest
- `pnpm preview` — просмотр собранной версии

## Структура

- `index.html` — HTML-оболочка с элементом `#root`
- `src/main.tsx` — точка входа, монтирует `<App />` через `createRoot`
- `src/App.tsx` — выводит три компонента `Todolist` (Todolist 1, 2, 3)
- `src/Todolist.tsx` — список задач: `TodolistHeader`, набор `Task`, `TodolistFilter`
- `src/TodolistHeader.tsx` — заголовок, поле ввода и кнопка «+»
- `src/Task.tsx` — строка задачи с чекбоксом и текстом
- `src/TodolistFilter.tsx` — кнопки All / Active / Completed
- `src/App.css`, `src/index.css` — стили
- `public/` — статические файлы (`vite.svg`)
- `docs/` — пустая папка
- `.idea/`, `node_modules/` — служебные каталоги IDE и зависимостей, их не редактировать

## Соглашения кода

- Компоненты — именованные экспорты в отдельных файлах (`export const Name = () => {...}`).
- Пропсы описываются типом `type NameProps = {...}` и передаются как `props`.
- Отступы — табы, строки в TSX — в одинарных кавычках (`className='app'`).
- Новые зависимости добавлять только если они уже используются в проекте или явно согласованы с пользователем.

## Ограничения и известные особенности

- Чекбокс в `Task` зафиксирован через `checked={true}`, текст задачи захардкожен.
- Поле ввода и кнопки в `TodolistHeader` и `TodolistFilter` не имеют обработчиков.
- Тестов в `src/` нет; при добавлении логики стоит покрыть её тестами Vitest.
- Перед завершением изменений запускать `pnpm build` (включает проверку типов через `tsc -b`).
